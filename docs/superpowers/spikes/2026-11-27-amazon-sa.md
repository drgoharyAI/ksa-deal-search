# Spike: amazon-sa.search (amazon.sa, English, SAR) - 2026-11-27

Status: PASS (Step 2 met). Bundled `amazon` op targets amazon.com only (baseUrl https://www.amazon.com), so a new op was learned for amazon.sa.

## Storefront verification (owner requirement: KSA store)
- Requests hit `www.amazon.sa` (spec match host `www.amazon.sa`, path `/s`; final URL `https://www.amazon.sa/s?k=...&language=en_AE`).
- Prices are `SAR nnn.nn` (every priced item in all 8 calls; 0 non-SAR).
- Page shows "Delivering to Riyadh" (seen in the browser capture and in a plain HTTP fetch). Language flyout "EN".
- Product URLs: built from `id` (ASIN) as `https://www.amazon.sa/dp/{id}`. Verify on the amazon.sa domain; not requested in the spike.
- Result `url` from the page is a sponsored click redirect (`/-/en/sspa/click?...`) for ads, so it is not picked.

## Recipe
- Site `amazon-sa`, op `search`, params `q`, `page`. Trigger `https://www.amazon.sa/s?k={q}&page={page}&language=en_AE`. `minTier: 1`.
- `--html` items `div[data-component-type=s-search-result]`, fields:
  - id `@data-asin`; title `h2`
  - price `.a-price:not(.a-text-price) .a-offscreen`
  - origPrice `.a-price.a-text-price .a-offscreen` (strike-through list price)
  - rating `span.a-icon-alt` ("4.6 out of 5 stars"); reviews `a[aria-label*=ratings]@aria-label` ("3,714 ratings")
  - image `img.s-image@src`
- Learned with two captures (earbuds p2, laptop p3) via `capture`, `add --from --from2`.
- The spec carries Chrome headers copied from the capture, no cookies.

## Field mapping to Product
id=id, title=title, price=parse("SAR 358.88"), currency="SAR", origPrice=parse(origPrice) when present, discount=derived: (1-price/origPrice)*100 (no discount badge picked), rating=parse leading number, reviews=parse number with commas, image, url=`https://www.amazon.sa/dp/{id}`.

- English titles, SAR prices. Tier 1 everywhere, `ms` 1.9-2.7 s per call (CLI wall time 6-15 s incl. npx start-up).
- page 2 differs from page 1: overlap only 7-9 of ~58 (repeated sponsored items). Dedupe by id downstream.
- origPrice present on roughly 20-80% of items; rating/reviews on ~90%.

## Sort
Not added. Amazon uses `&s=price-asc-rank` (also `price-desc-rank`, `review-rank`, `date-desc-rank`); untested, not in the op.

## Bait-style option pricing
Items show the price of the default variant/offer. A few items have no price (variants, unavailable); those lack `price` (1-4 per page). Treat unpriced items as dropped. origPrice is the seller list price and may be inflated, so discount is a weak signal. Sponsored results are mixed in.

## Concerns
- First batch had intermittent `ECONNRESET` (class error, tier 1, "retry safe"); a retry succeeded. Adapter needs 1-2 retries.
- Amazon may blocks bursts; keep call volume low (total ~25 requests used).
- `downlink`/`rtt` header warnings from add (kept constant) are harmless.
